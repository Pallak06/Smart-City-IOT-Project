# Problem Statement

Modern cities face increasing challenges related to safety, energy consumption, traffic control, and 
emergency responsiveness. Traditional manual systems cannot efficiently monitor the entire urban environment 
or respond quickly to incidents such as fires or suspicious activity.

This project addresses these challenges by creating a simulated Smart City environment in Cisco Packet Tracer 
that uses IoT technology to:

- Automate street lighting based on motion and ambient light
- Detect smoke and trigger fire alerts
- Monitor public spaces using smart cameras
- Send real-time data to a central server for analysis and alerts

The goal is to demonstrate how IoT can help cities become smarter, safer, and more efficient.
