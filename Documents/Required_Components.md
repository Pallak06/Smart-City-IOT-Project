# Required Components

This project uses Cisco Packet Tracer to simulate IoT devices and smart city applications. 
The following components are required to build the complete system:

---

## Software Requirements
- Cisco Packet Tracer (Version 7.3 or above)
- Optional: Screen recording software for demo video
- Optional: Diagram tools like Fritzing/TinkerCad (for explanations)

---

## Hardware Components (Virtual IoT Devices)
- Smart Cameras (for surveillance)
- Smart Street Lamps
- Motion Sensors
- Light Sensors
- Smoke Sensors
- Temperature Sensors
- Home Gateway / IoT Gateway
- IoT Server
- PCs or Tablets (for monitoring)
- Alarm/Buzzer devices

---

## Network Components
- Routers
- Switches
- Wireless Access Points
- Cloud (for WAN simulation)
- Copper straight-through cables
- Wireless communication links
